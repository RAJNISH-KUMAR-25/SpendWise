# SpendWise - Personal Expense Tracker

SpendWise is a full-stack personal expense tracker built with Java, Spring Boot, React, and MySQL. It provides CRUD expense management, categories, filters, summary statistics, validation, centralized error handling, and a responsive dashboard.

## Tech Stack

- Backend: Java 17+, Spring Boot 3.5.16, Spring Web, Spring Data JPA, Bean Validation
- Build: Maven
- Frontend: React 19.3, Vite 8.3.1, Axios
- Database: MySQL 8+
- API: REST / JSON
- Styling: Responsive custom CSS
- Optional: Docker Compose


## Features

- Add, edit, and delete expenses
- Category-based expense management
- Date and search filters
- Expense summary statistics
- Category spending breakdown
- Input validation
- Centralized exception handling
- MySQL persistence
- Responsive React dashboard

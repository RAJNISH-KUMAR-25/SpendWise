# SpendWise – Personal Expense Tracker

SpendWise is a full-stack personal expense tracker built for a Java/Spring Boot portfolio. It provides CRUD expense management, categories, filters, summary statistics, category spending breakdowns, validation, centralized error handling, MySQL persistence, and a responsive React dashboard.

## Tech stack

- Backend: Java 17+, Spring Boot 3.5.16, Spring Web, Spring Data JPA, Bean Validation
- Build: Maven
- Frontend: React 19.3, Vite 8.3.1, Axios 1.20.0
- Database: MySQL 8+
- API: REST / JSON
- Styling: responsive custom CSS
- Optional: Docker Compose for MySQL + backend + frontend

Spring Boot 3.5.16 is used here to stay within the requested Spring Boot 3.x line. It was the final OSS release in the 3.5 generation as of June 2026. The frontend uses the current React 19.3 and Vite 8.x stack.
